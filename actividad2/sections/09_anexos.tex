\section{Notas de limitacion}

\begin{itemize}
  \item No se afirma ejecucion de \texttt{slam\_gmapping}, Hector ROS ni Google
  Cartographer real; las variantes son reproducciones reducidas dentro de
  CoppeliaSim.
  \item El sensor se representa con los 16 ultrasonidos del Pioneer visualizados
  como rayos tipo LiDAR 2D, suficiente para la actividad y para comparar mapas.
  \item La planificacion local por waypoint no reemplaza a A* global, D* o RRT;
  es una regla practica para evitar bloqueos en una celda pequena.
  \item Los modos LQR/NMPC del benchmark de control se conservan como
  aproximaciones comparativas; la defensa principal se basa en los metodos
  clasicos trazables y validados.
\end{itemize}
