\chapter{Validacion y trazabilidad}

La validacion se diseno para demostrar comportamiento, no solo compilacion. Se
evalua si la escena existe, si los objetos clave estan presentes, si los scripts
estan embebidos, si las tareas se completan, si Bill se mueve, si las acciones
visuales ocurren, si el sistema anticolision se activa, si el estimador queda
acotado y si los sensores publican rayos visibles.

\section{Senales exportadas}

Las senales principales usadas para logs y plots son:

\begin{itemize}
  \item Tarea: \texttt{phase1TaskState}, \texttt{phase1TaskId},
  \texttt{phase1CompletedTaskCount}.
  \item Movimiento: \texttt{phase1MotionMode}, \texttt{phase1PlannerMode},
  \texttt{phase1DistanceToTarget}.
  \item Seguridad: \texttt{phase1MinObstacleDistance},
  \texttt{phase1ObstacleRisk}, \texttt{phase1SensorRayCount}.
  \item Estimacion: \texttt{phase1EstimatedPose}, \texttt{phase1PoseError},
  \texttt{phase1KalmanCovariance}.
  \item Mapeo: \texttt{phase1SlamLandmarkCount},
  \texttt{phase1SlamUpdates}, \texttt{phase1GridOccupiedCells}.
  \item Bill: \texttt{phase1B1Station}, \texttt{phase1B1Action},
  \texttt{phase1B1MovedDistance}.
  \item Energia: \texttt{phase1BatteryLevel}, \texttt{phase1BatteryMode},
  \texttt{phase1Charging}.
\end{itemize}

\section{Reproducibilidad}

El flujo reproducible queda:

\begin{enumerate}
  \item Construir y validar escena:
  \path{python actividad2/coppeliasim/build_phase1_basic_scene.py}.
  \item Exportar corrida base:
  \path{python actividad2/coppeliasim/run_phase1_slam_export.py}.
  \item Comparar SLAM:
  \path{python actividad2/coppeliasim/run_phase1_slam_comparison.py}.
  \item Generar plots:
  \path{python actividad2/coppeliasim/plot_phase1_slam_comparison.py}.
  \item Compilar informe:
  \path{pdflatex -> bibtex -> pdflatex -> pdflatex}.
\end{enumerate}
